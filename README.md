A program that writes one line to `/output/entry.txt` (57 characters, inside the 1–200 character gate): "This meeting could have been an email, so here it is: no." The line is the replacement itself: it delivers the whole meeting's verdict in a single word, so after it nobody can justify holding the meeting at all.

## Run it

```sh
python3 main.py
```
